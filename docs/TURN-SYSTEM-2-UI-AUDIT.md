## Tests requiring semantic migration

- `tests/sprint6-tutorial.test.js`: lesson harness and capture/retreat assertions assume capture on first `endTurn`; replace with assertions that same Turn persists through second window and capture waits for second end. Preserve inventory, illegal-action no-mutation, passive and actual Commander active coverage.
- `tests/sprint11-training.test.js`: keep six legal scenarios; assert actual normal windows rather than calling every opponent action a Counter. Smoke expiry still requires correct owner starts, not global paired Turn increment alone.
- `tests/sprint13-session.test.js`: capture/forced-retreat fixture at line128 assumes first-window capture. Move assertion to paired resolution; add reconnect checks in first/second/nested response and idempotent Turn-End checkpoint coverage.
- `tests/sprint13-protocol.test.js`: projection privacy assertions must include new timing context but retain hidden draws, reserve order, capabilities and cosmetics exclusion.
- `tests/sprint12-replay.test.js`: active-state clone fixture sets `passiveTurn`; explicit window stamps/phase must be covered. Deterministic engine dispatch still cannot use ambient clock/randomness.
- Existing browser scripts consume tutorial lesson IDs/indices and `data-action="end-turn"`; retaining those selectors avoids unnecessary UI-test breakage. Browser smoke must additionally prove Turn1 first window → Turn1 second window → Turn2, and no page-scroll/art-ratio regressions.
