# Sprint 12 — card rendering audit

The final after-art browser audit covered **every one of the 155 battlefield designs** in Collection, Arsenal, the actual match hand and full-card inspection. All full card faces retain the canonical **5:7** ratio. The test passed 184 rendering contexts and decoded all 106 current image sources (91 refined painted cards, five preserved faction atlases and ten unchanged illustrated Commander portraits). A separate responsive pass verified twenty contexts: Collection/Arsenal at 1920×1080, 1600×900, 1366×768, 1280×720, 900×600 and 390×844; match hands at the four large sizes plus 1093×614 and 1067×600; full-card briefings at 1366×768 and 390×844. It ran no balance campaigns and completed no competitive matches.

Manual inspection separately accepted all forty Tactical painted sources and actual 200×280 card faces after seventeen focal-point repairs. Final Tactical grades are **A 0 / B 40 / C 0 / D 0**; each reason and final source hash is preserved in [the after review](SPRINT12-ART-AUDIT-TACTICAL-AFTER.md). The legacy reviewer independently accepted all 115 older designs as B after framing and role repairs. Together the battlefield library is **A 0 / B 155 / C 0 / D 0**; ten unchanged off-lane Commanders remain the separate A benchmark. Source decode and aspect-ratio tests did not assign these visual grades.

The art-only CSS repair changes Collection's vertical alignment and makes `.art-refined` painted images fill each art window with `background-size: cover`. This scales both axes uniformly; a card's art mapping supplies the focal point. The three legacy and seventeen Tactical focal corrections change only metadata, leaving source and encoded runtime bytes unchanged. Atlas quadrants and approved Commander portrait files remain unchanged. Battlefield and training thumbnails remain compact rather than being turned into full card frames.
