# Turn System 2.0 — Card Timing Migration

Audited from the authoritative v1.2.0 live catalogue (Balance profile `sprint12`) before gameplay migration. The new live `sprint15` profile implements this timing contract; historical profiles retain their original text and cadence. Core deterministic verification covers all 155 legal card resolves and all ten Commander activations; full release integration results are recorded separately. All 155 cards are audited: 31 per faction. All 47 core timing tests pass, including one exhaustive fixture resolving every card and ten separate Commander activation/serialization fixtures. All printed numeric stats, costs, modes, unique restrictions, artwork, rarity and cosmetic state remain unchanged. Historical profiles remain historical; do not rewrite bare `data.js` or old JSON report text.

The text edits affect 48 cards. Unchanged rows are deliberately included so every card has a timing decision. Shared deployment/readiness/Capacity rules apply to all permanents and Orders even where card text does not repeat them.

## Timing schedule

A = Turn Start; B = Action Window Start; C = nested Response/Counter; D = Action Window End; E = Turn End; F = Match/once-per-match or persistent event rule; G = historical-only serialization. Ordinary deploy/move/attack/Order commands resolve inside the current Action Window; this list describes their scheduled triggers, budgets, expiry and response nesting rather than relabeling ordinary actions as start triggers.

The paired Turn contains FIRST then SECOND, with fixed match initiative. Player-specific starts remain sequential. True Turn-End territorial resolution evaluates the surviving board only after SECOND. The root rules specification is authoritative if it selects a different documented formula.

## Casualty-loop preservation and required fixtures

The live `salvageRecovery` branch in engine.js destroy already shares `scavengedTurn` and Nothing Wasted; do not transplant the independent historical branch. eligible casualty cause is combat, enemyEffect or displacementFailure with an enemy killer. Sacrifice, spentTrap/rulesResolution, allied costs and reclaim are not eligible. Lethally wounded simultaneous Scavenge sources cannot salvage before removal. A nearby surviving source receives attribution; the Commander covers casualties elsewhere; attribution must not create a second budget. Wounded reclaim is not Commander Recover the Fallen: reclaim retains wounds; the active remains a paid once-per-match discard recovery that starts without wounds.

Required deterministic tests: two eligible casualties in different windows of the same Turn draw once; next Turn grants one new allowance; multiple Scavenge sources + Nothing Wasted draw once; simultaneous lethal source never triggers; Sacrifice produces no dividend; forced displacement at E uses the same already-used budget; reclaim/redeploy retains wounds and cannot form a free repeated full-heal loop; serialized used budget survives reconnect and does not reset at SECOND start.

This document records the complete pre-migration audit and implemented current-profile text. `TURN-SYSTEM-2-RULES.md` supplies the authoritative net-pressure capture formula. `tests/sprint15-turns.test.js` verifies the core contract; release integration, public multiplayer and packaged results are recorded in the release validation documentation.
